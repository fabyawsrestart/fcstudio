# Home FCStudio: estrutura para o Elementor

Figma: https://www.figma.com/design/PKsxXxLyCBGTdAUC2Zvlci (página "Site · Home")
Desktop 1440 px (conteúdo 1140 px) e mobile 390 px. Cores e fontes: `../marca/tokens.css`.

## Configuração global no Elementor
- **Site Settings > Global Colors:** Primária `#168A5B`, Secundária `#1F2933`, Texto `#6B7280`, Destaque `#F2C98A`. Extras: `#0F6643`, `#E3F2EB`, `#F6F8F7`, `#CBD2D9`.
- **Global Fonts:** Primária (títulos) Morganite ou Anton, caixa alta. Texto Montserrat 16/160%. Botão Montserrat SemiBold 16.
- **Layout:** largura do container 1140 px. Espaço entre seções 112 px (desktop) e 64 px (mobile).
- **Botões:** raio 999 px, padding 18/28.
